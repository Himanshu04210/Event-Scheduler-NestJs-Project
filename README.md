# Event-Scheduler-NestJs-Project

The Event Scheduler System is a web-based application built using JavaScript, TypeScript, Node.js, Express.js, Next.js, and MySQL to manage event scheduling efficiently. It enables users to create, update, and track events, with real-time notifications and calendar integration. The system ensures secure authentication, role-based access control, and optimized database interactions, providing a seamless experience for event planning and management.
